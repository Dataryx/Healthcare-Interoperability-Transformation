# Million Claim Challenge evidence

Each `episode-NNN/` folder is a published run packet: what we ran, what we
measured, and what the operator console showed. Use these for reproducibility,
not as a podcast production kit.

Typical contents:

| File | Purpose |
| --- | --- |
| `README.txt` | What this episode is and how to read the files |
| `article.txt` | Write-up of the run |
| `benchmark-results.txt` | Numbers, environment, interpretation |
| `screenshots/` | Console captures from the run |

Keep data synthetic. Do not commit audio, video, or huge binaries.
